# fink-fat-ades

Pure ADES (Astrometry Data Exchange Standard) and Minor Planet Center (MPC)
logic for Fink-FAT. It is shared by the root `fink-fat submit` CLI and by
[`fink-fat-explorer`](../fink-fat-explorer/README.md) (lineage-page ADES
export, submission dashboard).

Every item is a pure function or a plain data type: no Postgres, no HTTP, no
filesystem, no async runtime. Each consumer does its own I/O and calls this
crate only to shape requests, parse responses and decide submission
eligibility. The CLI and the web app therefore always agree on what a valid
ADES document and an eligible lineage are.

## Modules

| Module | Role |
| --- | --- |
| `model` | `trkSub` normalization, band-code mapping, epoch conversion, singleton-night filtering, non-blocking quality advisories. |
| `xml` | `quick-xml` / `serde` structs mirroring `submit.xsd`, and the `build_ades_document` builder. |
| `xml_format` | Pretty-printing of ADES XML for display. |
| `schema_validation` | Local re-implementation of the `submit.xsd` constraints: a fast, synchronous validity check before submission. |
| `mpc_submission` | Request shaping and response parsing for MPC's `submit_xml` / `submit_xml_test` endpoints and their status pages. |
| `submission_status_api` | Response parsing for MPC's JSON Submission Status API. |
| `wamo` | Request body and response parsing for MPC's WAMO per-observation status API. |
| `quality_tier` | The `QualityTier` cascade and its query text, shared by the CLI eligibility gate and the explorer homepage badge. |
| `submitter_config` | `SubmitterConfig`, the submitter / telescope identity used by `submit --submitter-config` and generated by the explorer form. |
| `format_epoch`, `lsst_band` | Small formatting helpers used by `model`. |
| `error` | `AdesError`, returned by every fallible function. |
