

# edge_ml_prediction

XGBoost binary classifier that distinguishes true inter-night edges (TP) from
false edges (FP) produced by the Fink-FAT linking pipeline.  The trained model
is exported to ONNX and consumed by the Rust engine at inference time.

---

## Prerequisites

- Python 3.12
- [PDM](https://pdm-project.org/) for dependency management

Install dependencies:

```bash
cd crates/fink-fat-eval/src/bin/edge_ml_prediction
pdm install
```

---

## Workflow

### 1 — Generate the edge feature dataset

Run from the **workspace root**:

```bash
cargo run --profile evaluation -p fink-fat-eval -- edge-eval \
  --alerts file:///path/to/sso_dataset_eval.parquet \
  --config crates/fink-fat-eval/eval_config.yml \
  --export-features crates/fink-fat-eval/src/bin/edge_ml_prediction/edge_features.parquet
```

This produces `edge_features.parquet` in the project directory.

### 2 — (Optional) Optimise hyperparameters with Optuna

Run from `crates/fink-fat-eval/src/bin/edge_ml_prediction`:

```bash
# Quick run — results written to xgb_params.yml
pdm run python src/optimize.py --write-best --storage sqlite:///optuna.db

# With the web dashboard (opens on http://localhost:8080 after optimisation)
pdm run python src/optimize.py --write-best --storage sqlite:///optuna.db --dashboard
```

Key flags:

| Flag | Default | Description |
|---|---|---|
| `--n-trials N` | `100` | Number of Optuna trials |
| `--hpo-sample-size N` | `150_000` | Training samples per trial (stratified subsample). Use `0` for the full dataset. |
| `--write-best` | off | Overwrite `xgb_params.yml` with the best found parameters |
| `--storage URL` | in-memory | SQLite or other Optuna storage URL (enables resumable studies) |
| `--dashboard` | off | Launch the Optuna Dashboard after optimisation |
| `--port N` | `8080` | Dashboard port |

To inspect a past study without re-running:

```bash
optuna-dashboard sqlite:///optuna.db
```

### 3 — Train the model

```bash
pdm run python src/train.py
```

Outputs:
- `models/edge_classifier.ubj` — XGBoost native binary
- `models/edge_classifier.onnx` — ONNX model consumed by the Rust engine
- `eval_plots/` — ROC, PR curve, feature importance plots

### 4 — Evaluate the model (Rust)

Run from the **workspace root**:

```bash
cargo run --profile evaluation -p fink-fat-eval -- model-eval \
  -f crates/fink-fat-eval/src/bin/edge_ml_prediction/edge_features.parquet \
  -x crates/fink-fat-eval/src/bin/edge_ml_prediction/xgb_params.yml \
  -p model_eval_plots
```

## Configuration

`xgb_params.yml` holds all hyperparameters and training settings.  The
`model` section is passed directly to `XGBClassifier`; the `training` section
controls split ratios, early stopping, and output paths.

```yaml
model:
  eval_metric: [logloss, aucpr]   # early stopping driven by aucpr
  n_estimators: 574
  max_depth: 10
  learning_rate: 0.065
  # ...

training:
  test_size: 0.15
  early_stopping_rounds: 20
  model_output: models/edge_classifier.ubj
  onnx_output: models/edge_classifier.onnx
  eval_plots_dir: eval_plots
```

## Project layout

```
edge_ml_prediction/
├── pyproject.toml
├── xgb_params.yml          # hyperparameters (edit or let optimize.py write it)
├── edge_features.parquet   # generated by cargo edge-eval (not versioned)
├── models/                 # trained model outputs (not versioned)
├── eval_plots/             # evaluation plots from train.py
└── src/
    ├── config.py           # feature columns, paths
    ├── data.py             # parquet loading and train/test split
    ├── train.py            # main training entry point
    ├── train_xgb.py        # model construction, fit, evaluate, ONNX export
    ├── optimize.py         # Optuna HPO entry point
    ├── data_inspection/    # feature distribution and correlation plots
    └── model_evaluation/   # ROC, PR, calibration plots
```
